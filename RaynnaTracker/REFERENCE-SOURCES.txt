License: GPL-3.0; see LICENSE-ClassicDB.txt.
The data in LootReference.lua is derived from this source, not from player logs.
Reproduction: tools/build_loot_reference.py in the tracker workspace verifies the
source blob and converts the SQL into Lua without executing SQL.

This is a Classic 1.12 reference snapshot, NOT verified Forever server data.
It can omit new or changed creatures/items. No online requests happen in game.
NPC IDs select the loot table. Names do not determine source matches.
Direct and resolvable single-roll reference/group probabilities are displayed.
Quest/condition-dependent direct rates are labeled conditional. Repeated pools,
ambiguous groups and duplicate paths show Chance unknown instead of false precision.
Item quality and item bonus/stat tooltips come from the running game client.

Additional item-source providers: installed QuestieDB (runtime read-only lookup of npcDrops, questRewards, vendors). Striking Staff 279844 reward correction verified 2026-11-13 at https://www.wowhead.com/forever/item=279844/striking-staff .
